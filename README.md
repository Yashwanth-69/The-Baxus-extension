# Baxus extension(The Honey Barrel) - Browser Extension

A smart browser extension that helps you find matching products on Baxus with real-time price comparisons and discount alerts.

## ✨ Features

- 🔍 **Smart Product Matching** - Advanced similarity detection for accurate matches
- 💰 **Price Comparison** - Instant price comparisons with Baxus listings
- 🚨 **Discount Alerts** - Get notified about significant discounts
- 📸 **Product Previews** - Visual matching with product images
- ⚡ **One-Click Access** - Direct links to Baxus product pages
- 🌐 **Universal Compatibility** - Works on most e-commerce websites


### Requirements
- Google Chrome (version 92 or newer)
- Git (for cloning repository)

### Step-by-Step Setup

1. **Get the Extension Files (INSTALLATION)**
- Clone the Repo or Download the zip file
   ```bash
   git clone https://github.com/Yashwanth-69/The-Baxus-extension.git
- You can refer to this video for installation [Installation of the extension Video](https://youtu.be/fxE6z9dhen8)

2. **Open Chrome extensions in your browser**
    - Navigate to chrome://extensions/
    - Tuen on Developer mode

3. **Load the Extension**
    - Click Load unpacked button
    - Select the cloned directory ie choose only -> /BAXUS EXTENSION (The Honey Barrel)/
    - click open folder and the extension will be loaded

4. **Pin the Extension (Optional but recommended)**
    - Click the puzzle icon in Chrome's toolbar
    - Pin The Baxus extension for quick access

### How to Use
- Browse any e-commerce website
- Click the Honey Barrel icon when viewing a product
- View instant price comparisons and matches
- Click "View Product" to see details on Baxus

### Troubleshooting

- #### Extension not loading?

  - Ensure you selected the root directory containing manifest.json
  - Verify Developer Mode is enabled
  - Check for error messages in extensions page

- #### No matches found?

  - Try refreshing the product page
  - Wait until the entire website loads
  - Ensure product has valid pricing information
  - Check network connection
